## 🏨 Hotel Booking Data Analysis Using Python

### 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of hotel booking data to understand booking patterns, customer preferences, and hotel demand. The dataset contains 119,390 records and 32 columns related to City Hotel and Resort Hotel reservations.

### 🎯 Project Objectives

* Analyze hotel booking trends over different years and months.
* Compare City Hotel and Resort Hotel bookings.
* Understand customer types and market segments.
* Explore customer countries and length of stay.
* Identify missing values and improve data quality.
* Visualize important patterns using graphs and charts.

### 🛠️ Technologies Used

* **Python** – Main programming language.
* **Pandas** – Data cleaning and manipulation.
* **NumPy** – Numerical operations.
* **Matplotlib** – Data visualization.
* **Seaborn** – Statistical graphs and charts.
* **Google Colab / Jupyter Notebook** – Writing and executing code.

### ⚙️ Project Workflow

1. Dataset collection and loading.
2. Data inspection and understanding.
3. Data cleaning and handling missing values.
4. Data preprocessing and feature creation.
5. Exploratory Data Analysis.
6. Graphical visualization of booking patterns.
7. Interpretation of results and conclusions.

### 📊 Key Insights

The analysis explores hotel type distribution, yearly and monthly booking patterns, customer types, market segments, countries, lead time, and length of stay. These findings help explain booking behavior and hotel demand.

### 💡 Project Outcome

This project demonstrates how Python libraries can be used to analyze real-world hotel booking data and present meaningful insights through data visualization. It is an EDA-based project and does not include a machine learning prediction model.
